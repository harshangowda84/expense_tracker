Spendly - Portable Edition v1.1.5
==================================

HOW TO RUN
==========
1. Double-click Spendly.bat (recommended)
   OR
   Double-click expense_tracker.exe directly

2. The application will start immediately
3. No installation required!

FEATURES
========
- Portable - run from any folder, USB stick, or network drive
- No installation - no admin rights needed
- No registry changes
- Delete folder to completely uninstall

SYSTEM REQUIREMENTS
===================
- Windows 10 or later
- ~100 MB disk space
- No additional software needed

TROUBLESHOOTING
===============
If the app doesn't start:
- Ensure all files are extracted together
- Don't move individual files - keep folder structure intact
- Try running as Administrator if needed
- Check Windows Defender isn't blocking it (add exception if needed)

FOLDER STRUCTURE
================
Spendly-Portable/
├── Spendly.bat              (Quick launcher)
├── expense_tracker.exe      (Main application)
├── flutter_windows.dll      (Flutter runtime)
├── *.dll files              (Dependencies)
├── data/                    (Application resources)
└── README.txt               (This file)

DISTRIBUTION
============
To share with others:
1. Zip the entire Spendly-Portable folder
2. Share the ZIP file
3. Users can extract and run without any installation
